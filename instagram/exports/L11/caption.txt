Estimating derivatives

A table can estimate a derivative when no formula is given.
A centered secant uses information from both directions.

1. Read the output change from the outer two rows.
2. Use the matching input interval, not just half of it.
3. This is an estimate in output units per input unit.

Remember: Finite tabular data does not usually determine an exact derivative.
